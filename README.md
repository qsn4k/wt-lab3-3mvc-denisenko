# wt-lab3-3mvc-denisenko

Лабораторная работа WT-3 по дисциплине «Web-технологии».

Предметная область: **Игровой сервис / Турниры**.

Основная сущность: **Player**.

Архитектура:
- `Models/Player.cs` — модель предметной области;
- `Views/PlayerView.cs` — отображение данных и меню;
- `Controllers/PlayerController.cs` — обработка действий пользователя;
- `Program.cs` — запуск контроллера.

Целевая платформа: **.NET 9.0**.
